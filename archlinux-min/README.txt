This is a minimal Arch Linux live ISO image which is small enough to fit on a Compact Disc (CD).

It features a minimal set of drivers and firmware required to boot and connect to Wi-Fi on most hardware
(Intel/AMD microcode and security processor firmware, Intel Wi-Fi and Realtek Wi-Fi/Ethernet).
Not included: Qualcomm Atheros firmware, Broadcom Firmware, Mediatek/Ralink Firmware, NVIDIA firmware, GPU drivers.

Extra software:
 - archez-installer: Install Arch Linux to your computer's disk drive
 - networkmanager: Connect to the internet with an easy to use text based GUI by running "nmtui"

Standard 80 minute (700MB) CDs typically store 700MiB (734.003MB) of data, but are labelled as 700MB (667.572MiB).
Older 74 minute (650MB) CDs tpyically store 650MiB (681.574MB) of data, but are labelled as 650MB (619.888MiB).
